# 🧬 PGD-Diff Peptide Generator

**PGD-Diff** is a diffusion-based framework for computational peptide sequence generation and design.

This Hugging Face Space provides an interactive **Streamlit** interface for generating peptide sequences using two PGD-Diff generation modes:

1. **General Generation**
2. **Conditional Generation**

Generated peptide sequences can be previewed directly in the web interface and downloaded in **FASTA** format.

---

## 🚀 Generation Modes

### 1. General Generation

General Generation produces peptide sequences **without specifying a cancer condition**.

This mode is designed for general peptide sequence generation using the pretrained PGD-Diff model.

**Model checkpoint:**

`data/output/pgd_diff/both_dual_encoder/last.ckpt`

---

### 2. Conditional Generation

Conditional Generation produces peptide sequences **conditioned on a specified cancer-related condition**.

This mode uses a prefix-tuned model to guide peptide sequence generation according to the selected condition.

**Model checkpoint:**

`models/prefix_tuned/last.ckpt`

---

## 📥 Output

The generated peptide sequences are displayed directly in the Streamlit interface.

Users can:

- Preview generated peptide sequences
- Generate multiple candidate sequences
- Select sequences of interest
- Download generated sequences in **FASTA format**
- Use the generated peptides for downstream computational analysis

Example FASTA output:

    >PGD-Diff_001
    MKTLLVLLAV...
    >PGD-Diff_002
    GIGKFLHSAK...
    >PGD-Diff_003
    FLPLLAGLAAN...

## 🖥️ Running Locally

Clone the repository and install the required dependencies.

    git clone <YOUR_REPOSITORY_URL>
    cd <YOUR_REPOSITORY_NAME>

Install dependencies:

    pip install -r requirements.txt

Then launch the Streamlit application:

    streamlit run app.py

The application will be available at the local Streamlit address shown in the terminal.

---

## 🔬 About PGD-Diff

PGD-Diff is designed for **computational peptide design** using diffusion-based sequence generation.

The framework supports both:

- **Unconditional/general peptide generation**
- **Condition-guided peptide generation**

The generated sequences can be further evaluated using downstream computational analyses such as:

- Sequence-property prediction
- Peptide activity prediction
- Structural analysis
- Candidate ranking
- Other computational peptide-design workflows

---

## ⚠️ Disclaimer

The peptide sequences generated by this Space are **computationally generated candidates**.

They should not be considered experimentally validated peptides or guaranteed to possess any specific biological activity.

Experimental validation and appropriate safety assessment are required before any biological application.
